# Sistema de gestión de taller mecánico

## Descripción
Proyecto académico que consiste en desarrollar un sistema para gestionar clientes, vehículos y reparaciones de un taller mecánico.

El sistema contará con una API REST desarrollada en Python utilizando FastAPI y SQLite, además de una aplicación cliente desarrollada en Java bajo el patrón de arquitectura MVC.

## Modelos del sistema
- **Cliente:** almacena la información de los clientes.
- **Vehículo:** registra los vehículos asociados a cada cliente.
- **Reparación:** almacena las reparaciones realizadas a cada vehículo.

## Tecnologías utilizadas
- Python
- FastAPI
- SQLModel
- SQLite
- Java
- Maven
- Jackson

## Estructura del proyecto
- `api/`: desarrollo de la API REST.
- `cliente/`: aplicación cliente Java.
- `docs/`: diagramas y documentación.
